# Cube Grid Online

Онлайн-игра с кубиком на сетке **50x40**:
- движение: **WASD**
- поставить блок: **Q** или левая кнопка мыши
- удалить блок: **E** или правая кнопка мыши

## Быстрый запуск

```bash
python launcher.py
```

или

```bash
./run-server.sh
```

После запуска откройте:
- `http://127.0.0.1:3000`

## Чтобы играли люди из другой страны

### Вариант 1 (просто): публичная ссылка через Cloudflare Tunnel
1. Установите `cloudflared` на машине, где запущен сервер.
2. Запустите:

```bash
python launcher.py --public
```

Лаунчер покажет `trycloudflare.com` URL — отправьте его друзьям, и они смогут зайти из любой страны.

### Вариант 2: через VPS/сервер с белым IP
1. Запустите приложение на VPS.
2. Откройте порт 3000 в firewall/security group.
3. Отдайте друзьям URL вида `http://<public-ip>:3000`.

### Вариант 3: домашний интернет
1. Сделайте проброс порта 3000 (port forwarding) на роутере.
2. Разрешите порт 3000 в firewall.
3. Отдайте ваш внешний IP и порт друзьям.

## Переменные окружения
- `HOST` (по умолчанию `0.0.0.0`)
- `PORT` (по умолчанию `3000`)
- `PUBLIC_TUNNEL=1` для `run-server.sh`

Пример:

```bash
HOST=0.0.0.0 PORT=3000 PUBLIC_TUNNEL=1 ./run-server.sh
```
